Cloud Storage AWS (Amazon S3)

Offload Odoo chatter attachments and document files directly to Amazon S3. Save server disk space, reduce hosting costs, and achieve infinite storage scalability.

Enterprise & Community Direct Browser-to-S3 Upload SigV4 Presigned URLs Auto CORS Setup

Zero Server Bottlenecks

Chatter attachments upload directly from the user's browser to S3 via presigned URLs. Large files won't block Odoo HTTP workers or consume server bandwidth.

Bank-Grade Security

No public bucket exposure. All operations utilize time-limited AWS SigV4 signed URLs. Bucket keys and credentials are fully isolated and neutralized in test environments.

Deduplication & Safety

Shared files across duplicate records are preserved. Deletions happen strictly post-commit to avoid data loss if database transactions roll back.

Key Features & Capabilities

Built natively for Odoo's cloud_storage ecosystem with enterprise-grade AWS integration.

Direct Chatter Upload

Direct client-to-bucket upload using presigned PUT requests. Works out-of-the-box with standard Odoo Chatter.

Fast Inline Previews & Downloads

PDF viewer and image previews load directly from S3. Original filenames are preserved via RFC-compliant Content-Disposition headers.

Server-Side Upload Fallback

Non-chatter binary attachments (e.g. form fields) exceeding the minimum file threshold are automatically pushed to S3 asynchronously.

Automated CORS Configuration

No manual bucket CORS tinkering! Odoo automatically sets up the required S3 CORS policy upon saving credentials.

Staging / Test Neutralization

Includes neutralize.sql to automatically wipe AWS credentials on staging/testing databases, preventing accidental production blob deletion.

Uninstall Protection Hook

Prevents module uninstallation if active attachments are stored in S3, safeguarding against accidental disconnection.

Architecture

How Direct Cloud Upload Works

High-performance architecture bypassing the Odoo application server for file payloads.

Request Signed URL

When attaching a file in the Chatter, Odoo generates a secure, time-limited presigned S3 PUT URL.

Direct Browser Upload

The user's browser transmits the file bytes directly to Amazon S3. Zero load on Odoo web workers.

Immediate Availability

Odoo stores the object reference. Files are served via presigned GET URLs with instant inline preview.

Simple 3-Minute Configuration

Step 1: Amazon IAM Policy

Create an IAM User with programmatic access and attach the following minimal policy (replace YOUR-BUCKET-NAME):

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "OdooCloudStorageBucketCORS",
            "Effect": "Allow",
            "Action": ["s3:PutBucketCORS"],
            "Resource": "arn:aws:s3:::YOUR-BUCKET-NAME"
        },
        {
            "Sid": "OdooCloudStorageObjectOperations",
            "Effect": "Allow",
            "Action": [
                "s3:PutObject",
                "s3:GetObject",
                "s3:DeleteObject"
            ],
            "Resource": "arn:aws:s3:::YOUR-BUCKET-NAME/*"
        }
    ]
}
Step 2: Odoo Settings
  1. Navigate to Settings > General Settings > Discuss / Cloud Storage.
  2. Select Amazon S3 as the Cloud Storage Provider.
  3. Input your Bucket Name, S3 Region (e.g. ap-southeast-3), Access Key ID, and Secret Access Key.
  4. Click Save. Odoo performs an automated connectivity & permissions test.
